## 一、头顶三个图标

### 位置与大小

- 悬在村民头顶**上方约 0.6 格**（比原版名字牌略高，避免遮挡）
- 图标尺寸 **0.35 格** 见方（约等于一个头颅的 1/3 宽）
- 三个图标**横排**，间距 0.08 格，整体居中于村民头顶
- 面向玩家（billboard），永远正对镜头

```
         ┌───┬───┬───┐
         │ ✓ │ ☠ │ 📢│   ← 0.35 格/个，间距 0.08
         └───┴───┴───┘
              ↕ 0.6 格
           ┌────────┐
           │  村民   │
           └────────┘
```

### 三个图标各自表达什么

| 位置 | 图标 | 绿色 | 红色 | 灰色 |
|---|---|---|---|---|
| 左 | 对勾 | 硬条件全满足 | 确定不满足 | 数据不可得 |
| 中 | 骷髅 | 正在被恐吓 | 没被恐吓 | 不适用 |
| 右 | 喇叭 | 具备闲聊基础 | 不具备 | 数据不可得 |

**灰色的存在很重要**：多人游戏里客户端拿不到服务端数据，
此时显示灰色问号，而不是红色叉。否则玩家会去拆一台本来正常的机器。

### 距离处理

- 超过 **32 格**不渲染（可在设置里调 8~64）
- 开启「随距离缩小」时，24 格外开始线性缩小到 70%
- 与村民之间有方块遮挡时**仍然显示**（透视），但透明度降到 60%
  - 理由：机器通常埋在建筑里，看不见图标就没法用

### 仅显示有问题的村民？

**不开这个开关**（保持"打开就能看见"）。
但提供设置项「只显示不能刷的村民」，默认关。

## 二、村民状态页

### 触发方式（按需求）

- 右键村民 → **若该村民有交易界面**：在原版交易界面**底部加一个按钮**
- 右键村民 → **若无交易界面**（如失业/婴儿）：直接打开状态页

### 布局

标题栏 + 五个分组，竖排列表。每行「标签 —— 值」，左侧标签灰白，右侧按状态着色。

```
┌──────────────────────────────────────┐
│ 村民状态 (#1234)                  [×] │
├──────────────────────────────────────┤
│ 位置: (128, 64, -40)                  │
│ 总判定: 还不能刷 — 睡觉已超过 20 分钟  │
├──────────────────────────────────────┤
│ ▸ 个体条件                            │
│   成年村民          满足              │
│   20 分钟内睡过觉    睡觉已超过20分钟  │  ← 红
│                       (30000 / 24000) │  ← 灰色小字
│   30 秒内未发现铁傀儡 满足             │
├──────────────────────────────────────┤
│ ▸ 触发状态                            │
│   处于恐吓状态      正在被恐吓  [悬停说明]│
│   处于闲聊状态      未在闲聊          │
├──────────────────────────────────────┤
│ ▸ 群体条件                            │
│   恐吓合格人数: 3 / 闲聊合格人数: 0    │
│   恐吓人数达标      满足 (3 / 3)       │
│   闲聊人数达标      不足 (0 / 5)       │  ← 红
├──────────────────────────────────────┤
│ ▸ 生成点                              │
│   有合法生成点      满足 (289 个位置)  │
├──────────────────────────────────────┤
│ 绑定的床: (130, 64, -38)              │
└──────────────────────────────────────┘
```

**尺寸**：宽 320、高随内容（约 300），内容超出时滚动。

**交互**：
- 悬停任意一行 → 显示该条件的完整说明（来自 lang 文件 `.desc`）
- 值里的 `(30000 / 24000)` 表示「当前值 / 门槛」，让玩家知道差多少

## 四、统计页

放在设置页的 **「统计」标签**里（不单独占快捷键，减少记忆负担）。

```
┌────────────────────────────────────────────┐
│  [ 开关 ]  [ 统计 ]  [ 关于 ]              │
├────────────────────────────────────────────┤
│  开始记录：第 12 天 14:32                  │
│  刷出铁傀儡：47 只                         │
│  判定次数：1832 次                         │
│  平均产量：31.4 只 / 小时                  │
├────────────────────────────────────────────┤
│  ▸ 刷新失败（按次数排序）                   │
│   #1234  睡觉已超过20分钟        218 次    │
│   #1235  没被恐吓                96 次     │
│   #1240  恐吓人数不足(1/3)       74 次     │
│   ...（最多 8 行，可滚动）                 │
├────────────────────────────────────────────┤
│  ▸ 按原因统计                              │
│   睡觉已超过20分钟              218        │
│   没被恐吓                       96        │
├────────────────────────────────────────────┤
│                        [ 清空统计 ]  [×]   │
└────────────────────────────────────────────┘
```

**「清空统计」需要二次确认**（点一次变成「确定？」再点一次），防止误触丢掉数据。

## 五、世界内绘制（三个可视化开关）

### 床连线（开关三）

- 从村民**脚部**到床**方块中心**画一条线
- 颜色：**青色** `#3FE0FF`
- 线宽 1.5 像素，始终可见（透视）

### 怪物恐吓连线（开关五）

- 从怪物**眼睛**到村民**眼睛**
- **生效的**：实线，**橙红色** `#FF7040`
- **距离不够的**：虚线，同色但透明度 50%
  - 虚线段长 0.25 格，间隔 0.15 格
- **视线被挡的**：点线（更短的点），表示"够近但看不见"

### 可刷范围框（开关四）

- 17×13×17 的线框，**黄色** `#FFD24A`
- 只在**玩家最近查看过的村民**周围显示（避免满屏都是框）
  - 判定：准星指向 8 格内的村民 → 显示该村民的框
  - 或者按住 Shift 显示所有 32 格内的框

### 傀儡检测范围框（开关六）

- 33×33×33 的线框，**紫色** `#B060FF`，透明度更低（这个框很大，容易糊屏）
- 显示规则同上（准星指向的村民）

## 六、需要你确认的 5 个点

1. **三个图标横排** 是否符合预期？还是想竖排 / 只要一个总状态？
2. **状态页宽度 320** 够不够？主要是 `(30000 / 24000)` 这类数值比较占宽。
3. **统计页放进设置页的标签** 行不行？还是要独立快捷键（比如 `K`）。
4. **可刷范围框只在准星指向村民时显示** —— 还是希望全部显示？
5. **灰色问号**这个设计你认可吗？（多人游戏拿不到数据时用）
