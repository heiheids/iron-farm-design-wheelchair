================================================================
备份与恢复说明
================================================================

从 2026-10-27 起，每次改动都会自动记录到 git 仓库，
出问题可以回滚到任意一个备份点。


----------------------------------------------------------------
一、日常：自动备份
----------------------------------------------------------------

每次改完代码，运行：

    .\tools\backup.ps1

或者带说明：

    .\tools\backup.ps1 -Message "改了漏斗清理周期"

重要节点可以打标签（方便以后按版本号找回）：

    .\tools\backup.ps1 -Tag v0.44.0

没改动时会自动跳过，不会产生空提交。


----------------------------------------------------------------
二、出问题了：怎么恢复
----------------------------------------------------------------

【情况 1】刚才改坏了，想撤销，回到上一次备份

    .\tools\restore.ps1 -Last

这会：
  · 把当前的改动丢弃
  · 但先把改动存成 build\rescue\dropped-<时间>.patch
    （万一又想找回，可以用 git apply 打回去）
  · 恢复到最近一次备份的状态

【情况 2】想回到某个历史版本

先看有哪些备份点：

    .\tools\restore.ps1 -List

然后按 hash 恢复（前面的 7 位就够）：

    .\tools\restore.ps1 -Hash 6641c0a

或者按标签：

    .\tools\restore.ps1 -Tag v0.43.0

恢复前会问一次 y/n，确认后才动。

【情况 3】只想看看现在改了什么

    .\tools\restore.ps1 -Check


----------------------------------------------------------------
三、注意
----------------------------------------------------------------

1. 恢复的是**源码**。已经构建好的 jar 还在各模块 build/libs 下，
   要重新构建才会在游戏里生效：

       .\tools\pack.ps1

2. 备份不包含：
   · .gradle（依赖缓存，543 MB）
   · build 目录（构建产物）
   · neoforge-*/build/moddev（反混淆产物，丢了要联网重下几 GB）
   · 已发布的 zip

   这些都能重新生成。源码才是有价值的部分（约 1.6 MB）。

3. 仓库位置：D:\工程-刷铁机设计轮椅\.git
   整个仓库只有 0.7 MB，即使几千次提交也不会占太多空间。


----------------------------------------------------------------
四、如果 git 仓库本身坏了
----------------------------------------------------------------

所有历史在 .git 目录里。想额外保险，可以定期把整个 .git
复制到别处（比如 U 盘、网盘）。它很小，复制很快。
