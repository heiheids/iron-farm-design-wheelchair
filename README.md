# 刷铁机设计轮椅 / Iron Farm Design Wheelchair

一个 Minecraft 模组，用来**诊断和调优铁傀儡农场**。

它会在村民头顶实时显示状态图标，告诉你每一只村民为什么刷不出铁傀儡——是没睡觉、没工作、被恐吓，还是村民数量不够。

---

## 功能

### 头顶状态图标

每个村民头顶显示三个独立图标，一眼看出卡在哪一环：

| 图标 | 含义 |
|---|---|
| 绿色对钩 | 这只村民已满足条件：成年 + 睡过觉 + 30 秒内没见过铁傀儡 |
| 红色骷髅 | 这只村民正在被恐吓（附近有威胁） |
| 红色喇叭 | 闲聊条件已满足（可以传播 gossip） |

三个图标独立判定、独立着色，直接对应原版的刷铁判定链。

### 统计页

按 `K` 打开设置，切到「统计」标签：

- 已记录时长（按游戏时间累计，开 tick 加速器会同步加速）
- 铁傀儡累计数量 / 每小时产量
- 铁锭产量估算（按每只 4 个的期望值）
- 平均离开检测范围用时
- 平均存活时长

### 实物统计

漏斗**输出方向**指向白色羊毛块时，漏斗内容会被销毁并记录。

统计内容：
- 累计销毁数量、每小时销毁速率
- 按物品种类细分（总数量 / 每小时）

用途：漏斗指向白色羊毛是常见的"垃圾销毁"手法。这个统计告诉你**到底销毁了什么**——避免把铁锭也一起扔进虚空。

> ⚠ 这个功能是**破坏性**的，默认关闭。在设置页「白色羊毛漏斗销毁」里手动开启。

## 安装

### 支持的版本

| Minecraft | Fabric | NeoForge |
|---|---|---|
| 1.21.1 | ✅ | ✅ |
| 26.3 | ✅ | ✅ |

从 [Releases](../../releases) 下载对应版本的 jar，放进 `.minecraft/mods/` 即可。

需要先安装对应的 mod loader（Fabric Loader 或 NeoForge）。

### 依赖

无第三方依赖。模组自带一个小型纯 Java 引擎（通过 jarJar / Jar-in-Jar 打包）。

---

## 使用

1. 进游戏，村民头顶会自动出现图标
2. 按 `K` 打开设置：
   - **开关** — 各图标的显示开关
   - **统计** — 产量数据
   - **关于** — 版本信息
3. 右键村民可以看单只的详细状态

---

## 从源码构建

需要 JDK 21（1.21.1）和 JDK 25（26.3）。

```bash
# 全部构建
./gradlew build

# 只构建某个版本
./gradlew :fabric-1.21.1:build
./gradlew :neoforge-26.3:build
```

产物在各模块的 `build/libs/` 下。

### 项目结构

```
engine/           纯 Java 判定引擎，零 Minecraft 依赖
fabric-1.21.1/    适配层：Fabric + 1.21.1
neoforge-1.21.1/  适配层：NeoForge + 1.21.1
fabric-26.3/      适配层：Fabric + 26.3
neoforge-26.3/    适配层：NeoForge + 26.3
tools/            打包与校验脚本
```

判定逻辑全部在 `engine` 里，适配层只负责把 Minecraft 的数据喂进去。这样同一套判定规则可以在四个加载器组合上运行，且能被单元测试覆盖。

### 测试

```bash
./gradlew :engine:test
```

## 已知限制

- **实物统计只在单人游戏生效**。多人服务器里客户端拿不到漏斗内容。
- 头顶图标需要在配置里开启（默认开启）。
- 26.3 的 NeoForge 构建需要联网拉取 NeoForm，首次构建较慢。
